# WebStock — Server Side

This folder contains the **Laravel** backend for [WebStock](../README.md).

## Quick start

```bash
cd server-side
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate
php artisan serve
```

## Tests

```bash
php artisan test
```

See the [root README](../README.md) for the full setup and deployment instructions.
